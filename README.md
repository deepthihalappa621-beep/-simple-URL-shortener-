# Simple URL Shortener

A web-based URL Shortener built using Python, Flask, and SQLite. This application allows users to convert long URLs into short, easy-to-share links. The system generates unique short codes, stores URL mappings in a database, and redirects users to the original website when the shortened URL is accessed.

## Features

* Shorten long URLs instantly
* Generate unique short links
* Store URL mappings using SQLite
* Automatic redirection to original URLs
* Simple and user-friendly interface
* Lightweight and easy to deploy

## Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS

## How It Works

1. Enter a long URL in the input field.
2. Click the "Shorten URL" button.
3. The application generates a unique short URL.
4. Users can access the short URL to be redirected to the original website.

This project demonstrates the fundamentals of web development, database integration, routing, and URL management using Flask.
